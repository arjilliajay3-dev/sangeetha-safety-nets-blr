## 1. Real-Site Photography Guidelines for Client

To ensure optimal visual performance, SEO ranking, and authentic local trust in Bengaluru:
- **Aspect Ratios**:
  - Hero Banners: `16:9` or `1920x1080` / `1600x900` landscape.
  - Service Cards: `4:3` or `1200x900` landscape.
  - Before / After & Case Studies: `4:3` or `1:1` square (`1000x1000`).
- **Resolution**: High-resolution originals (minimum 1200px on the shortest edge).
- **Format**: Upload in `.webp`, `.jpg`, or `.png`. The build pipeline will compress and generate responsive WebP sizes.
- **Lighting & Composition**: Daylight exterior shots showing clean balcony railings, floor parapets, and panoramic Bengaluru skyline views without blur or finger obstructions.

## 3. Checklist for Updating Codebase Upon Photo Delivery

1. Name the incoming photo using the standard format:
   `sangeetha-[service-slug]-[location-slug].webp`
2. Optimize file size to `<150KB` using Sharp or Squoosh at 85% quality.
3. Save to `public/images/services/` or `public/images/projects/`.
4. Update `src/utils/servicesData.ts` and `src/data/projects.ts` with the new file path.
5. Provide descriptive alt text referencing the real job locality in Bengaluru.
